# Day 2 — Advanced SQL for Data Analytics
**Task:** Use window functions, CTEs and grouped aggregations to calculate daily cost trends and usage metrics.

**Deliverables:** `advanced_analytics.sql` contains eight queries. `output/` is reserved for your CSV query results.

**Run demo:** From repository root run `python scripts/load_demo_db.py`, then:
`sqlite3 Datasets/demo.db < Day_02_Advanced_SQL/advanced_analytics.sql`
If the sqlite3 CLI is unavailable, open `Datasets/demo.db` with DB Browser for SQLite or execute each statement in VS Code SQLite extension.

**CSV evidence:** Export each query result from your SQL client as CSV and save with query number, e.g. `output/q1_daily_spend.csv`. A CSV export is evidence only after you execute the query yourself.
